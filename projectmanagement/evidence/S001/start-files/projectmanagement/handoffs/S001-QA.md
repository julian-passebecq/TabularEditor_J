## Defects and supporting source review

For each finding include BUG/backlog ID, severity, reproducible trigger, expected
and observed behavior, affected source location, evidence, suspected cause marked
as hypothesis, owner and regression needed. Highlight any weak/vacuous test oracle.
Routine source inspection supports the lead; it does not replace the lead audit.

## Consolidated routing

- Ordinary specified-behavior defects: one REWORK batch for developer, followed by
  targeted retest plus affected regressions.
- Architecture/privacy/data-loss/lifetime uncertainty: concise decision packet
  for lead; continue independent tests.
- Milestone verified: READY_FOR_LEAD_REVIEW; lead still decides acceptance.
- Missing environment: exact remaining Desktop/XMLA/native session checklist,
  marked BLOCKED_ENV only after confirming that prerequisite is unavailable.

Update BACKLOG, REGISTERS and STATUS with factual results and next actor. Include
pass-sizing feedback available from the developer/user. End with the exact next
prompt from README, tailored to rework or lead review.
