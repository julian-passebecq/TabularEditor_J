## Existing stabilization logic worth retaining

- The AMO `Server` alias resolves the previously observed compiler ambiguity.
- Initial SplitContainer sizes now allow actual dialog construction and resize
  smoke to pass; this does not certify all DPI/focus interaction.
- Selected-text execution preserves whitespace-selection behavior. The history
  copies terminal result metadata without retaining result row arrays.
- The UI's unexpected-provider exception fallback is generic; the AMO adapter
  still supplies its own raw-message path as described above.
- DAX document open commits state after successful decode; saves use a sibling
  temporary file and hash-based external-change checks; replacement prompts
  preserve drafts on cancellation/failure; recalled history becomes untitled.
- The document hash check and filesystem replacement are not one transaction
  with another editor. This limitation is already described and should remain
  visible. Do not turn it into a stronger recovery/concurrency claim.
