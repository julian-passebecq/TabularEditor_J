# S3 DAX workspace: slice note (2026-10-13)

Branch `claude/pbibench-s3-daxworkspace` from `d652e0f` (S2/S4/S5 integrated). Not pushed, not merged. Verify: `Scripts/Verify-PbiBench.ps1`, evidence `.tools/verify-S3` (git-ignored).

## Implemented
- **DAX-013 multiple documents.** Core `Documents/DocumentSet.cs` holds the tabs: at most 32, unique ids, each file open in one tab only (full path, case-insensitive), right/left neighbour on close, close-all order (active tab first, then left to right). `DaxDocument` gains `Id` (stable GUID, valid RecoveryStore id), `Generation` (New/Open), `Title`, `CheckDisk()` (SHA-256: Unchanged/Changed/Missing/Unreadable) and `AcknowledgeExternalChange()` (explicit "keep mine": the next Save may overwrite or recreate the file).
  Host `PbiBenchDaxWorkbenchForm.Tabs.cs`: each tab has its own RichTextBox (its own undo, caret and results). File menu: New tab Ctrl+N, Open Ctrl+O (new tab, reuses an untouched empty tab, switches to an already open file), Open in current tab, Save, Save As, Save All Ctrl+Alt+S, Close tab Ctrl+W/Ctrl+F4/middle-click, Close all tabs, Next/Previous Ctrl+Tab/Ctrl+Shift+Tab (also Ctrl+PgDn/PgUp), Check files for external changes. While a query runs, tabs cannot be switched or closed.
- **S001 guards per tab.** A tab's Generation and TextRevision are stamps taken from global monotonic counters, so they are unique across tabs. Remote formatter responses are keyed by document id plus that tab's stamps: a response lands only in the tab that asked (even after switching), and is discarded after an edit in that tab, a replacement, a reload, or when the tab is closed. S2 completion sessions and F8 advisory state use the active tab's stamps, so they are rejected in any other tab. The old reflected fields `_queryEditor`, `_document` and `_documentGeneration` now follow the active tab (the existing Rework01/DaxDocument/Formatter smokes are unchanged and pass).
- **Dirty handling.** Close tab, Close all and window close ask Save / Don't save / Cancel for each dirty tab, and show that tab while asking. Cancel closes nothing. Closing the last tab leaves one empty draft.
- **External change.** On tab activation, on window activation and from the menu (no FileSystemWatcher), each tab's file is compared by hash. Background tabs get "(changed on disk)" / "(deleted on disk)" in the tab title; the active tab shows a yellow banner with **Reload from disk** (asks for confirmation when edits would be lost) or **Keep my version** (Dismiss when the file is unreadable). Nothing is reloaded or overwritten without a choice; Save keeps refusing until one is made.
- **Opt-in recovery.** `PbiBenchDaxWorkbenchForm.Recovery.cs` uses the S4 `RecoveryStore` (kind `dax`, no duplicated storage code). It is off by default. Opting in needs the disclosure to be accepted (marker `%LOCALAPPDATA%\TE2Enhanced\recovery.dax.optin`, separate from the script workspace consent). Dirty tabs are copied 3 s after the last edit. A copy is deleted when its tab is saved, replaced after "Don't save", closed, or when the window close is confirmed. Copies survive a crash and are offered on open as unsaved tabs titled "recovered (…)". Copies that fail the hash check are skipped and reported. The File > Recovery menu restores, turns recovery off, and deletes DAX copies only (script copies are never touched).
- **DAX-014 DAX Studio handoff.** Core `Dax/DaxStudioHandoff.cs` sends only two positional arguments: the server label and the database label (the shape Power BI External Tools uses for DAX Studio, `"%server%" "%database%"`). Labels with `=`, `;`, quotes, control characters, connection-string keywords or more than 512 characters are refused and never echoed back. Host `PbiBenchDaxStudioLauncher.cs` looks for DaxStudio.exe in this order: the configured path (`%LOCALAPPDATA%\TE2Enhanced\daxstudio-path.txt`, set with File > DAX Studio location…), then the registry (Uninstall `DAX Studio*` InstallLocation and App Paths, HKCU/HKLM, 64/32), then `%LOCALAPPDATA%\Programs\DAX Studio`, `Program Files\DAX Studio` and `Program Files (x86)\DAX Studio`. It starts DaxStudio.exe directly (`UseShellExecute=false`, no cmd) and puts the query (the selection, if any) on the clipboard. Without DAX Studio, without a live connection, with a refused label or when the start fails (tried once), it saves the tab as .dax using the normal Save/Save As flow and reports the reason and the path. Workbench: File > Open in DAX Studio (Ctrl+Shift+D). Tools > PbiBench menu (`PbiBenchMenu.DaxWorkspace.cs`): "Open model in DAX Studio (handoff)" and "Delete DAX recovery copies".

## Exact limits
- External change is checked on activation and on demand, not live. Detection is by content hash. Each check reads up to 32 files of at most 4 MiB.
- `DaxDocument.Save` is unchanged (pre-existing temp write + `File.Replace` on the user's .dax file); the OBS-001 exposure there is the same as before S3. Recovery writes never replace files in place (RecoveryStore).
- Recovery: 2 Mi characters per document, RecoveryStore retention (7 days / 50 documents across kinds). Text only; caret, results and history are not recovered.
- History stays shared across tabs and loads into the active tab. One query and one remote format run at a time per window. The workbench stays modal.
- DAX Studio receives no query or file argument (its command line for that is not verified); the query goes through the clipboard. The connected launch needs the TE2 model to be a live connection with a server name.

## Light QA must check natively
1. Tabs: Ctrl+N/O/W/F4/Tab, middle-click close, focus after switching, DPI 150 %, the title (n/m), dirty markers, Escape with several dirty tabs.
2. Edit an open .dax in another editor, then return to the Workbench: banner, Reload, Keep, and delete/rename of the file.
3. Recovery: opt in, kill TE2 with unsaved tabs, reopen the Workbench: restore prompt, recovered titles, files under `%LOCALAPPDATA%\TE2Enhanced`, delete menu.
4. DAX Studio installed (user and machine install, path with spaces) with Power BI Desktop open: does DAX Studio connect to the server/database passed positionally? Also check not installed, set location, and an XMLA workspace label.
5. Remote format on tab A, switch to B before the reply: A is formatted and B is untouched.
