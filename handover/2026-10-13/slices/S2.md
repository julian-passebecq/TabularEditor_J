## Exact limits
- Lexical analysis only: no DAX grammar/binder; VAR scope is "declared earlier in the text", not block-accurate. Unknown function hint relies on the pinned TE2 vocabulary (newer engine functions are flagged as advisory only).
- Catalog is curated (224 of ~350 pinned words); other words complete with "no local signature". Parameter names/arity are best-effort and never block anything.
- Bare `[x]` is accepted if any model column/measure has that name (row context is not resolved); `'T'[Measure]` with another table's measure is accepted.
- Expression-editor assistance is per session (not persisted) and off by default; inserts use TE2's own editor undo (Ctrl+Z), the model change happens only when the user accepts the edit.
- Usage "unused" = unused by model expressions only; report usage unknown until S6 supplies external counts. Usage builds on every Semantic View open (linear in total DAX length; untested on very large models).
